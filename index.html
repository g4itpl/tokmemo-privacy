톡갈피 개인정보처리방침

시행일: 2026년 8월 4일

톡갈피(이하 "앱")는 카카오톡에서 사용자가 남긴 메모와 사용자가 선택한 다른 채팅의 유용한 정보를 기기 안에서 정리하는 독립 앱입니다. 카카오 및 카카오톡과 제휴하거나 카카오가 제공하는 공식 앱이 아닙니다.

1. 접근하는 정보

  • 알림 접근을 허용한 경우: 카카오톡 알림의 방 이름, 보낸 사람 또는 알림 제목, 메시지 내용, 알림 시각. 메모 분류와 최근 알림 대화의 방별 자동 보관에 사용합니다.
  • 접근성 화면 수집을 허용한 경우: 사용자가 직접 연 카카오톡 화면에 보이는 방 이름과 메시지 텍스트. 나와의 채팅 메모 저장과 사용자가 직접 시작한 안 읽은 대화 정리에 사용합니다.
  • 사용자가 직접 공유하거나 가져온 경우: 텍스트, 링크, 사진, 동영상, 문서와 파일 정보
  • 사용자가 모바일 AI API를 설정한 경우: 선택한 AI 제공자, 모델 이름과 본인이 입력한 API 키. API 키는 Android 보안 저장소를 이용해 암호화하여 이 기기에 보관하고 요약 요청을 인증하는 데만 사용합니다.
  • 사용자가 PC CLI AI 연결을 설정한 경우: 연결 주소, 접근 토큰과 선택한 AI 제공자. 접근 토큰은 요약 요청을 인증하는 데만 사용합니다.
  • 앱 설정: 수집할 방 이름, 필터, 차단 목록, 테마와 같은 사용 환경
  • 일정 등록 앱을 고를 때: 일정 작성을 지원하는 설치 앱의 이름과 아이콘. 선택 화면을 만드는 데만 사용하며 전체 설치 앱 목록을 수집하거나 전송하지 않습니다.

2. 이용 목적과 처리 방식

정보는 메모 분류, 검색, 일정·링크·장소·파일 실행, 중복 제거, 최근 알림 대화의 방별 자동 보관, 안 읽은 대화 정리와 사용자 요청에 따른 백업·복원 및 AI 요약에만 사용됩니다. 알림으로 들어온 카카오톡 메시지는 최근 대화 보관함에 방별로 저장되며 명확한 인증정보는 제외합니다. 접근성 화면 수집은 카카오톡 앱으로 범위를 제한하며 사용자가 직접 시작하고 연 화면에 보이는 텍스트만 처리합니다.

3. 외부 전송과 제3자 제공

앱은 개발자가 운영하는 메모 서버, 광고 서비스 또는 분석 서비스로 메모를 자동 전송하지 않습니다. 인터넷 권한은 사용자가 직접 설정한 모바일 AI API 또는 PC CLI AI 연결과 Google Play 업데이트 화면에 사용합니다. 사용자가 AI 요약을 직접 실행하면 수집한 대화 텍스트가 사용자가 선택한 AI 제공자에게 직접 전송되거나 사용자가 입력한 PC CLI 연결 주소를 거쳐 전송되며, 이후 처리는 해당 연결 서비스와 AI 제공자의 개인정보처리방침 및 계정·요금 설정을 따릅니다. AI 연결을 설정하지 않으면 대화 내용은 AI 요약을 위해 기기 밖으로 전송되지 않습니다. 사용자가 복사, 일정 등록, 링크 열기, 지도 검색 또는 첨부파일 열기를 직접 선택한 경우에도 필요한 내용이 시스템 클립보드나 사용자가 선택한 외부 앱으로 전달됩니다.

4. 저장 위치와 보유 기간

메모와 앱으로 복사된 첨부파일은 Android 앱 전용 저장공간에 보관됩니다. 알림에서 자동 보관한 최근 대화는 최대 14일 동안 기기 안에 저장되며 방별 읽음 처리, 전체 삭제 또는 앱 제거로 더 일찍 삭제할 수 있습니다. 사용자가 화면에서 직접 수집한 안 읽은 대화 결과는 새 수집을 시작할 때 교체됩니다. 전체 삭제 기능은 메모, 앱 내부 첨부파일, 자동 보관 알림 대화, 임시 화면 수집 결과와 AI 연결 설정을 함께 삭제합니다.

5. 암호화 백업

사용자가 백업을 요청할 때만 선택한 위치에 .tokmemo 파일을 만듭니다. 백업은 사용자가 정한 암호로 AES-GCM 방식으로 암호화되며 암호는 앱에 저장되지 않습니다. 암호를 잊으면 백업을 복원할 수 없습니다. 사용자가 클라우드 저장소를 백업 위치로 선택하면 암호화된 파일은 해당 저장소의 정책에 따라 동기화될 수 있습니다. 앱의 전체 삭제나 앱 제거는 사용자가 외부 위치에 만든 백업 파일까지 삭제하지 않으므로 해당 파일은 저장한 위치에서 직접 관리해야 합니다.

6. 민감정보 보호

명확한 일회용 인증번호, OTP, 비밀번호 또는 복구 코드로 판단되는 메시지는 저장 단계에서 제외합니다. 사용자는 휴대폰 잠금 확인을 이용한 앱 잠금을 선택할 수 있으며, 잠금 사용 중에는 화면 캡처와 최근 앱 미리보기에서도 메모 내용을 숨깁니다.

7. 사용자의 선택과 삭제

알림 접근과 접근성 화면 수집은 Android 설정에서 언제든 해제할 수 있습니다. 앱에서 자동 보관 대화의 방별 읽음 처리, 화면 수집 결과 삭제, AI 연결 해제, 개별 메모 삭제, 특정 방·사이트에서 그만 받기, 전체 데이터 삭제, 암호화 백업과 복원을 이용할 수 있습니다. 전체 삭제는 메모, 앱 내부 첨부파일, 자동 보관 알림 대화, 임시 화면 수집 결과, 마지막 수집 기록, 수집 방 이름, 그만 받기로 한 목록과 AI 연결 설정을 함께 지웁니다.

8. 아동의 개인정보

앱은 만 13세 미만 아동을 대상으로 설계되지 않았으며 아동의 개인정보를 의도적으로 수집하지 않습니다.

9. 방침 변경

앱의 데이터 처리 방식이 달라지면 시행 전에 이 페이지와 앱 안의 안내를 갱신합니다.

10. 문의

개인정보 관련 문의는 공개 문의 페이지를 이용할 수 있습니다. 공개 문의에는 실제 대화 내용, 백업 암호 또는 민감정보를 작성하지 마세요.
